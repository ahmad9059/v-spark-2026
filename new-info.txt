Web Development Competition
Rules, Marks and Submission
1. Overview
Build a working web application and submit it with your source code and a live link. Please read all
rules carefully before you start.
Total marks: 100 | Time allowed: 120 minutes (2 hours)

4. How Your Work Is Checked
• GitHub and Google Drive code review.
• Live testing of the public URL.
• Testing login, database, storage, and API for real.
• Security check (no exposed secrets, safe inputs).
• Short live demo with questions from judges.
5. Participant Checklist
• Registration, login, logout, and protected routes work.
• Database is connected and full CRUD works.
• File upload and retrieval work.
• At least one external API works, with error handling.
• App is deployed and the public URL works.
• GitHub repository has the complete code.
• Full project folder is uploaded to Google Drive.
• README is complete and includes environment variable names.
• No real secrets or .env files uploaded.
• Name, registration number, and all links are ready.
• Everything is submitted before the deadline
